## 📁 Model Dosyalarının Kurulumu

`Model` klasörünün içerisinde bulunan dosyalar GameLoop'un ilgili dizinine aktarılmalıdır.

**Kurulum yolu:**

```text
C:\TxGameAssistant\ui
```

1. `Model` klasörünü açın.
2. İçerisindeki dosyaları seçin.
3. Aşağıdaki dizine gidin:

```text
C:\TxGameAssistant\ui
```

4. Dosyaları ilgili klasöre kopyalayın.
5. Dosya değiştirme uyarısı gelirse mevcut dosyalarınızı yedekledikten sonra devam edin.

> Not: GameLoop'un kurulu olduğu dizin farklıysa kendi kurulum konumunuzu kullanın.

## ⚙️ Kurulum Sırası

1. China GameLoop 64-Bit sürümünü kurun.
2. GameLoop'un tamamen kapalı olduğundan emin olun.
3. `Model` klasöründeki dosyaları belirtilen dizine aktarın.
4. `RBX Alt Tune.bat` dosyasını yönetici olarak çalıştırın.
5. GameLoop'u başlatmak için ilgili giriş BAT dosyasını kullanın.
6. Oyunun grafik ve FPS ayarlarını videodaki şekilde yapılandırın.
